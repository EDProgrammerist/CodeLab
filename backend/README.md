# CodeLab API

Laravel REST API, separate from the React frontend. Use the PHP 8.4 Docker runtime and Composer lockfile.

See [local development](../docs/local-development.md) for environment setup, startup and checks. The current API exposes GET /api/v1/health. Domain and authentication endpoints are planned in [API design](../docs/api-design.md).

No migrations have been applied in Phase 2.1. The stock migrations are scaffold files awaiting Phase 3 adaptation.
